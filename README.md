# Watershed Runoff Forecasting Toolkit

**Citation:** Salazar, R., & Brenner, J. (2026). Watershed Runoff Forecasting Toolkit. Hydrology Methods, 19(3), 210-226.
**Maintainer:** Research Software Group (software@cedarbrook-research.org)
**Project ID:** RES-4648-WATERSHED

## Repository Status
Public release complete. The code, configuration and sample data in this repository are available for external reuse.

## Overview
A calibration and forecasting toolkit for short-horizon watershed runoff prediction using open rainfall and stream-gauge data.

## Repository Layout
- `src/` — source code
- `data/` — input datasets and schema notes
- `experiments/` — experiment configuration files
- `notebooks/` — exploratory analysis notebooks
- `tests/` — smoke tests

## Usage
See the experiment configuration files under `experiments/` for the supported runs.
